installer.ts getFullVersion(): reads <installPath>/source.properties, parses Pkg.Revision,
splits on '-' -> for r26d the output equals 26.3.11579264. If detection fails the output
is EMPTY (only a warning) — hence the workflow's fail-closed comparison is required:
empty output or any value != NDK_PKG_REVISION (26.3.11579264) aborts the build.

CONCLUSION: NDK_VERSION=r26d (action input) + NDK_PKG_REVISION=26.3.11579264 (check-only)
is the correct split. The NDK version itself is UNCHANGED (r26d, N8 frozen); this is an
input-format fix, not an upgrade. The v4.3 workflow value 26.3.11579264 passed directly
to the input would have produced a 404 download URL (build would fail).
